```
       GAME・2008
 02 ≡ チョコレイト・ディスコ
       GAME・2008
 03 ≡ Spending all my time
       JPN・2011            AM未配信
  :
 11 ≡ スパーリング・スター
 12 ┄┄┄┄┄┄ 空き ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
 13 ┄┄┄┄┄┄ 空き ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
◆━━━━━━ ここまでが Side U ━━━━━━◆

    ≡ edge
    ≡ Dream Fighter

═════════ 下に固定されるバー ═════════

   あと2曲                  (押せない)
```

- **`n / 13` は下に固定されるバーに置く**。画面の高さに関係なく常に見える
- 各行: 番号、ドラッグ用のつまみ `≡`、曲名（省略せず、長ければ折り返す）、2 行目に「作品・年」。Apple Music にない曲には `AM未配信` を付ける
- 空き枠は点線で表示する。押すと曲を探すシートが開く
- **タグはカテゴリごとに 1 行の横スクロール**。右端をフェードさせて、続きがあることを示す。選択中は `✓` と塗りの両方で示す
- `⋯` のメニュー: リセット、ヘルプ（保存について）、プライバシーなどのページ

### 1.2 下へスクロールした状態（表示領域の高さ 600px 以上の端末）

```
▌あもん の Side U                   ✎
▌#深夜に #浸りたい #隠れ名曲          ← 上に固定される要約
──────────────────────────────────────
 06 ≡ ワンルーム・ディスコ
 07 ≡ レーザービーム
  :
═════════════════════════════════════

```

- 名前・タグの入力欄がスクロールで隠れたら、**2 行の要約を上に固定する**
- `✎` を押すと一番上に戻り、名前の入力欄にフォーカスする
- 高さが 600px 未満の端末（折りたたみ端末を開いた状態、横向きのスマホなど）では要約を出さず、下のバーだけを固定する

### 1.3 行を操作する（タップで展開）

```
 04 ≡ コンピューターシティ
       GAME・2008
┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃ 05 ≡ ワンルーム・ディスコ
┃       ⊿・2009
┃ [↑上へ][↓下へ][候補へ][削除]
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
 06 ≡ レーザービーム
       JPN・2011
```

- 行をタップすると選択状態になり、操作ボタンが出る。同時に選択できる行は 1 つだけ
- **移動しても選択は曲についていく**ので、`↑上へ` を続けて押せばどんどん上に動かせる
- 候補の行では `[候補へ]` の代わりに `[Side U へ]` を出す
- ボタンの動き（境目をまたぐ場合など）は `DESIGN.md` の §4.10 のとおり
- `≡` をドラッグすれば、選択しなくても並べ替えられる
- 同じ行をもう一度タップする、ほかの場所をタップする、Esc キーを押す、のどれかで選択を解除する
- アクセシビリティ: 行は `aria-expanded` 付きのボタン。移動のたびに「ワンルーム・ディスコ、4 曲目」と読み上げる（`aria-live`）

### 1.4 13曲目が候補に移ったときの通知

```
 ┌──────────────────────────────────┐
 │『レーザービーム』が候補に移りました │
 │                       [ 取り消す ]│
 └──────────────────────────────────┘
 11/13  [ ＋ 曲を追加 ]  [ 完成する ]
```

- 下のバーのすぐ上に 5 秒ほど表示する。削除したときも同じ形（「『○○』を削除しました [取り消す]」）

## 3. 完成・共有の画面（`/u/:payload`）

### 3.1 作った本人が開いた場合

```
← 編集に戻る                          ⋯
──────────────────────────────────────
あもん の Side U ができました

 ┌─────────────┐┌──────────┐┌──
 │             ││          ││
 │   9:16      ││  正方形  ││ 透
 │             ││          ││
 │ SIDE U      ││ SIDE U   ││
 │ 01 ポリ…    ││ 01 …     ││
 │  :          │└──────────┘└──
 │ 13 …        │
 │ #深夜に …   │
 └─────────────┘
 9:16          正方形       背景透過
 [共有][コピー][保存]  [共有][コピー]…
        ●  ○  ○        ← 何枚目かを示す点

リンク
 [ sideu.perfumehub.app/u/1Ab…  コピー ]
──────────────────────────────────────
Apple Music
 [ Apple MusicにSide Uをつくる ]
 ※ 13曲中1曲が Apple Music にありません
```

- **3 種類の画像を横に並べて見せる**。スマホでは横スクロール（`scroll-snap`）にし、次の画像の端が少し見えるようにして、横に続きがあることを示す。画面幅が広い場合は 3 列に並べる
- **画像がそのまま「カード」になる**。HTML のカードは別に作らない
- 各画像の下に `共有` `コピー` `保存` を置く。環境で使えないボタンは出さない（`DESIGN.md` §6.3）
- 画像は `<img>` で表示する（Canvas で描いた PNG を `blob:` URL にしたもの）。`alt` に全文を入れて読み上げられるようにする。iOS では長押しで「写真に保存」「コピー」もできる
- 画像は **9:16 と正方形の 2 枚**。それぞれの下に背景の切り替え `(模様あり | 透過)` を置く
- `透過` を選ぶと、透明な部分がわかるように市松模様の上に表示し、スイッチ `文字の後ろを暗くする`（黒 → 透明のグラデーション。初期値はオン）を出す
- 切り替えたら、その形の画像だけを作り直す
- 画像の下に「画像の説明文（ALT）」: 説明文（`alt` と同じ文章）を表示し、`コピー` ボタンを付ける。X などに投稿するときに画像の説明として貼り付けてもらう

`alt` の例:

```
SIDE U。あもん の 13 曲。1 ポリリズム、2 チョコレイト・ディスコ、…、13 Magic of Love。タグ: 深夜に、浸りたい、隠れ名曲。
```

### 3.2 ほかの人が開いた場合

```
SIDE U                              ⋯
──────────────────────────────────────
╱╲ 幾何学模様（背景の飾り）  ╱╲
あもん さんの Side U
#深夜に  #浸りたい  #隠れ名曲

 01  ポリリズム
      GAME・2008
 02  チョコレイト・ディスコ
      GAME・2008
  :
 13  Magic of Love
      LEVEL3・2013
──────────────────────────────────────
 [ Apple Musicでこのプレイリストをつくる ]
 ※ 13曲中1曲が Apple Music にありません
──────────────────────────────────────
自分のSide Uをつくる
 [ 新しくつくる ]
 [ この13曲をもとにつくる ]
──────────────────────────────────────
 SIDE Uは非公式のファン制作ツールです。…
```

- **HTML で表示する**（Canvas の画像にしない）。曲名は普通のテキストなので、選択・コピー・読み上げ・文字サイズの変更ができる
- 幾何学模様は同じ payload から同じ形を作り、背景の飾りとして表示する（`aria-hidden`）
- 共有画像（3 種類）はこの画面には出さない
- 操作は 2 つのまとまり:
  - **Apple Musicでこのプレイリストをつくる**: 流れは本人の場合と同じ（`DESIGN.md` §8.2）
  - **自分のSide Uをつくる**: `新しくつくる`（空の状態から）/ `この13曲をもとにつくる`（13 曲とタグを読み込む）
- `新しくつくる` / `この13曲をもとにつくる` を押したとき、下書きがあれば概要を見せて破棄してよいか確認する（`DESIGN.md` §7.2）
- 名前がない場合は「誰かの Side U」と表示する
- 「本人かどうか」は、payload が自分の下書きの Side U（13 曲とタグ）と一致するかで判定する。一致しなければ、自分で作ったものでもこの画面になる

```

プレイリスト名  SIDE U - あもん
曲数            12曲（13曲中）

Apple Music にない曲（2）
┌ 3曲目 Koe - Interlude          この曲は入りません   ← 差し替え候補がない
┌ 5曲目 すみっコディスコ-Movie Ver.
│ ( ) 「すみっコディスコ」に差し替える              ← 配信されている別バージョン
│ (●) この曲を除いてつくる                          ← 初期値（勝手に差し替えない）

Apple ID でサインインし、あなたのライブラリに非公開のプレイリストを 1 つつくります。…
 [ Apple Music でつくる（12曲） ]

```

- 作成中（サインイン中・作成中）は閉じられない
- 完了: 「『SIDE U - あもん』をつくりました（12曲）」と `ミュージックで開く`
- 失敗: キャンセル / 利用登録なし / 通信エラー / その他 をそれぞれの文言で表示し、`もう一度` でやり直せる
- 開発者トークンがない・期限切れのときは、ボタンを押せなくして「現在使えません」と表示する（ほかの機能には影響しない）

## 7. 保存できない環境での案内

- 編集画面の上に案内を出す（`localStorage` に書き込めない場合と、アプリ内ブラウザと判定できた場合）
- LINE のアプリ内ブラウザでは `ブラウザで開く` ボタン（`openExternalBrowser=1`）
- それ以外は「メニューから『ブラウザで開く』」と `くわしく`（`/help/storage`）
- `/help/storage`: アプリごとの開き直し方、シークレットモード、Safari がしばらく使わないサイトのデータを消すこと、ほかの端末への引き継ぎ方
